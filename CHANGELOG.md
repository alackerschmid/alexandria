## 1.0.0 (2026-06-26)

Initial release.

### Features

* FRBR-style works/series model with Wikidata enrichment pipeline
* ISBN barcode scanning (camera + manual entry) with Google Books / OpenLibrary fallback
* Per-user library with read-status tracking (unread / reading / read)
* Series completeness view
* Custom field definitions per user
* Book metadata overrides per user
* Guest mode (up to 3 scans, migrated on register/login)
* Dark/light theme, English/German i18n
* Cloudflare Pages (frontend) + Cloudflare Worker + D1 (backend)
