## 1.0.0 (2026-07-25)

The first stable release of The Library of Alexandria — a personal book catalogue for people with too many books and not enough shelf space.

### Cataloguing

* ISBN barcode scanning via camera, with manual ISBN entry and title search for books without a usable barcode
* Automatic metadata from Google Books and OpenLibrary — title, author, cover, publisher, language, page count, publication date
* Background Wikidata enrichment — series membership, genres, awards, original publication year, first lines, narrative locations
* Goodreads CSV import: shelf-to-reading-status mapping, matching of ISBN-less rows against your existing library, and updating existing entries instead of discarding data
* Guest mode — scan up to 3 books before creating an account, migrated on register or login

### Your library

* FRBR-style works/editions model — editions of the same work group into a single card, with edition swapping and reference-page fallback
* Reading status (unread / reading / read), owning status, and a 0–10 rating per book
* Series completeness view — every volume in a series and exactly which you own
* Grouping, filtering, sorting, and pagination across grid and list views, persisted between sessions
* Library statistics — read/unread counts, top authors, language distribution, median publication year, page stats
* Custom field definitions per user (text, number, select) and per-user metadata overrides

### Interface

* Appearance presets — accent colour, paper and typeface themes, dark and light mode
* Preferences sync across devices
* English and German localisation
* Mobile-first layout with persistent navigation and sticky search
* Accessibility pass across the app — focus management, ARIA, reduced-motion support

### Platform

* Cloudflare Pages (frontend) + Cloudflare Worker with D1 (backend)
* Rate limiting on scan creation and imports, shared metadata cache across users
* Automated type-check, lint, worker tests, and D1 migrations on deploy
